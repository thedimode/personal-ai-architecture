# Security Policy

## Reporting a vulnerability

If you discover a security-relevant issue in this specification (for example, a schema or protocol pattern that creates a privacy or safety risk for implementers), please report it privately. Do not file a public GitHub issue.

Email: **timothyshin2025@gmail.com**

You can expect an initial response within seven days. If a coordinated disclosure is appropriate, we will work with you on a timeline.

## Supported versions

| Version | Supported |
|---|---|
| v0.9 (Draft) | Yes |

Pre-1.0 draft versions receive security responses on a best-effort basis. v1.0+ will follow a formal supported-versions policy.
